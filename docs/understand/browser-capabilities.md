# Browser capabilities

Open /diagnostics in the browser you plan to use. **Available** means the API is exposed, or, for WebGL2, the browser created a context. Camera and clipboard access, sensor readings, and a WebGPU adapter depend on device hardware, permissions, and browser policy. The page does not request permission or open a picker. A **Needs HTTPS** result means the origin must change before the API can be checked. Use the [phone HTTPS guide](../ship/dev-https.md).

## What to record at H3

Record the device, operating system, browser version, whether the page is secure, and any unexpected diagnostic results. Also note whether camera or motion access works when the corresponding feature requests permission.
