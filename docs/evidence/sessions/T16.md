# T16 · Live document camera

- Build · 2026-11-26 · Codex app · GPT-6.2 Astra at high, as requested in “do in high”
- Capabilities — shell execution, Playwright, screenshot inspection and GitHub Actions
- The phone shares its rear camera over the paired WebRTC connection. The laptop finds the page in a vision worker and uses a WebGL2 shader to rectify incoming frames. The user can adjust contrast and brightness or find the page again.
- The homography test compares all nine matrix entries with OpenCV for an identity transform and a tilted page to six decimal places. The paired browser test compares a corner pixel in the raw video and rendered canvas to confirm the background was cropped. It also checks graphics context loss, stopping the stream, accessibility and the 360 px layout.
- The requested 1080p and 30 fps are camera preferences. The browser fixture uses 320 × 240 video. Physical-device performance remains for T21 and the SmartDoc gate is waiting on H5.
